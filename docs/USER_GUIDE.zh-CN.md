# 光场 LIGHTFIELD：从下载到独立完成一套人像布光

这是一款在浏览器中运行的三维人像布光练习工具，用头颈肩人像帮助你观察鼻影、面部明暗与光线方向。所有模型、贴图和渲染库都随软件提供，下载后可以离线练习。

**本指南适用于 1.1.0。** 新的相机操作见 [相机完整指南](CAMERA_GUIDE.zh-CN.md)。下载对应版本的源码或 Windows 便携版，附件以 GitHub Releases 实际内容为准。

## 一、下载正确的文件

在 GitHub 仓库首页，找到 **Releases（发行版）**，打开最新版本，再展开 **Assets（附件）**。

| 你的情况 | 应下载的文件 |
| --- | --- |
| Windows 10 / 11，64 位，想直接使用 | 当前发行版名称含 `windows-x64` 的 ZIP |
| macOS / Linux，或想研究修改代码 | 当前发行版名称含 `source` 的 ZIP |
| 想检查下载文件是否完整 | 同时下载 `SHA256SUMS.txt` |

Windows 普通用户请选择 **windows-x64.zip**。GitHub 自动生成的 `Source code (zip)` 是源码，和免安装的 Windows 便携版不同。

## 二、Windows 解压与启动

1. 下载 ZIP 后，在资源管理器中右键选择「全部解压」。
2. 打开解压后的 `lightfield-studio` 文件夹。应能看到 `Lightfield.exe`、`dist` 文件夹、说明文档等文件。
3. 双击 **Lightfield.exe**。也可以双击中文名 **启动光场.cmd**。
4. 一个深色的「光场」启动器窗口会出现，并自动在默认浏览器打开摄影棚。
5. **使用时保留启动器窗口。** 关闭启动器窗口会同时停止本地服务；下次需要使用时重新双击 EXE 即可。

请完整保留整个解压文件夹。只把 EXE 单独复制到桌面，或直接在 ZIP 中运行，都可能找不到模型和网页。

Windows 版无需安装 Node.js、Python，无需注册账号，也无需登录 ChatGPT。它使用系统的 .NET Framework 4.x；Windows 10 / 11 通常已经自带。浏览器需要支持 WebGL 2。

### 浏览器没有自动打开怎么办

在启动器中点击「打开摄影棚」，或复制窗口显示的地址到 Edge / Chrome 等支持 WebGL 2 的浏览器。地址通常是 `http://127.0.0.1:4173/`。

若端口已被其他程序占用，软件会尝试后续端口。**以启动器实际显示的地址为准。** `127.0.0.1` 表示这台电脑，不是一个需要联网访问的网站。

## 三、先认识界面

- **左侧「灯光」**：选择主光、补光或轮廓光，开关灯具，调节灯位与光质。
- **中间人像画面**：观察实时光照；顶部可切换「相机视角」和「三维场景」。
- **左侧灯光下方「灯位图」**：展开后从上方看灯、人像和相机的位置，可直接拖动灯具。
- **右侧「人物与相机」**：分「人物」「相机」「场景」三页。人物页选性别、发型、发色、摆动与转向；相机页有画幅、快门、镜头、距离四个模块；场景页选背景和材质。
- **下方十一种方法**：经典鼻影、宽窄光、柔光与美妆、氛围与明暗；可用分类筛选。
- **工作区下方光影控制**：主补入射光比、环境光、背景亮度和人像曝光补偿。
- **构图与姿态**：构图偏移、抬低头与侧倾；画幅和辅助线已移至右侧相机页。
- **观察与比较**：全画面直方图、亮度检查、保存 A 与 A/B 并排对照。
- **布光指南与六堂练习**：每种方法的灯位、观察步骤和排错，以及带三项自查的课程。
- **顶部「我的拍摄」**：查看模拟拍摄的照片、下载 JPG、恢复照片当时的布光。

手机或较窄的浏览器窗口会把控制面板排在画面下方，向下滚动即可找到。

## 四、第一堂练习：伦勃朗光

### 第一步：载入预设

点击下方 **「伦勃朗光」**。主光会回到侧上方，补光与轮廓光关闭，人像转向回到正面。
初始主光参数为：水平角度 **−50°**、俯照角度 **30°**、距离 **2.0 m**、相对强度 **70%**、光源直径 **60 cm**、色温 **5200 K**。

这些数值是软件中的练习起点，不是实拍时必须照抄的参数。

### 第二步：找鼻影与暗侧三角亮区

观察鼻子投向暗侧的影子。伦勃朗光的典型特征，是鼻影与脸颊暗部连接，暗侧眼睛下方仍保留一小块三角形亮区。

试着让水平角度一次变化两三度，再微调俯照角度。不要只判断数值是否等于 45°，应看脸上的明暗关系。
当前男女模型均保留原有眼睛，可观察眼部受光、鼻梁、眼窝和颧骨投影；模型不模拟自主眼神和表情变化。

### 第三步：比较硬光与柔光

减小「光源直径」，阴影边缘会更明确；增大直径，明暗过渡会更柔和。
「光照强度」改变亮度，「光源直径」主要改变阴影过渡，两项可以分开比较。

### 第四步：试一点补光

选择左侧 **「补光」**，打开灯具开关，把强度先设得较低，再逐步增加。
观察暗部细节是否更清楚，以及三角亮区是否被过强的补光冲淡。想回到起点时，重新点「伦勃朗光」即可。

### 第五步：模拟拍摄

满意后点击画面下方的圆形快门，或在页面画面区域使用 **空格键**。如果焦点停留在按钮、下拉菜单或输入控件中，直接点击快门按钮最方便。

## 五、怎样移动灯与人像

### 拖动俯视灯位图

展开左侧灯光面板下方的「灯位图」，拖动一个灯具图标，会同时改变其水平角度和距离。俯照角度仍在灯光滑块中调整。
点击某盏灯会选中它；也可用左侧「主光 / 补光 / 轮廓光」标签切换。

键盘用户可聚焦灯具图标：左右方向键改变水平角度，上下方向键改变距离。

### 相机视角与三维场景

- **相机视角**：拖动画面旋转人像；滚轮在可选焦距之间切换。也可用右侧「人像转向」和「焦距」控件精确调整。
- **三维场景**：拖动画面环绕观察摄影棚，滚轮缩放，查看灯与人像的空间关系。
- **复位视角**：在相机视角恢复正面与默认焦距；在三维场景恢复摄影棚观察位置。

切换观察视角不会让灯光自动跟着相机走。左侧的灯具总开关关闭后，该灯的照明才会消失。

### 光质参数

| 参数 | 用来观察什么 |
| --- | --- |
| 水平角度 | 灯从左前方、正前方、侧方或侧后方照来时的变化 |
| 俯照角度 | 光源在眼睛上方的高度与向下照射方向 |
| 距人像 | 光源与脸的距离，以及亮度、阴影变化 |
| 光照强度 | 当前灯的相对亮度，不代表真实灯具瓦秒 |
| 光源直径 | 阴影边缘的硬软程度 |
| 色温 | 偏暖或偏冷的照明颜色 |

## 六、其他预设怎么练

- **环状光**：观察鼻影向侧下方延伸，但不接到脸颊暗部时的效果。
- **分割光**：观察主光在正侧面时，脸部一半明亮、一半变暗的效果。
- **蝴蝶光**：观察正面高位光照在鼻下形成的小阴影，以及眼窝暗部的变化。

载入方法会重设三盏灯、相机、背景、曝光、单灯观察和头部姿态，保留当前人像材质。若想保留当前自定义布光，先导出方案或拍一张照片。

## 七、相机、材质与辅助工具

焦距可选 50、85、105 mm。光圈、ISO 和快门会联动预览亮度；这不是完整的相机光学模拟，**光圈不会产生真实景深虚化**，快门也不模拟闪光同步。

「肤色 / 石膏」便于比较材质对明暗观察的影响。背景色可自由切换。

画面左侧的辅助按钮提供构图线、均匀照明对比和三角光观察提示。三角提示框只是参考，不是自动识别结果；实际亮区会随灯位、脸型与转头方向改变。

## 八、照片怎样保存与恢复

1. 按快门拍摄，按当前画幅生成 JPG：4:5 为 1200 × 1500、1:1 为 1200 × 1200、3:2 为 1500 × 1000。
2. 点击顶部「我的拍摄」，或画面下方最近照片的缩略图。
3. 点击 **「下载 JPG」**，将照片保存到浏览器下载位置。
4. 点击 **「恢复布光」**，载入该照片拍摄时的灯光、相机和场景设置。

相册最多保留最近 **八张**照片；继续拍摄会淘汰最早的照片。重要作品应及时下载。

照片与方案只保存在当前浏览器的本地存储里，不会传到 GitHub、ChatGPT 或远程服务器。换浏览器、换端口或清理浏览器数据后，可能看不到原来的相册。

## 九、导出方案，下次接着练

点击右上角 **「导出方案」**，下载 JSON 文件。建议给文件起容易辨认的名字，例如 `伦勃朗-小柔光箱.json`。
之后点击左侧底部 **「导入布光方案」**，选择该 JSON 文件，即可恢复设置。

JSON 方案保存灯光与场景参数，不保存照片。想同时保留照片与设置，请分别下载 JPG 和 JSON。

## 十、常见问题

### 双击 EXE 报错，或网页提示找不到文件

确认 ZIP 已完整解压，且 EXE 旁边保留完整的 `dist` 文件夹。确认使用的是 Windows 10 / 11 64 位环境，并具备 .NET Framework 4.x。

### 网页打开了，但人像一直加载或画面空白

先确认启动器仍开着，再根据启动器地址重新打开页面。使用支持 WebGL 2 的浏览器，并检查浏览器硬件加速是否可用。
若仍然失败，可在 GitHub Issues 描述系统、浏览器和报错。提交截图前请遮住姓名、邮箱、其他标签页等个人信息。

### 页面变得很暗或太亮

重新点一次经典预设，检查主光开关与强度。也请检查 ISO、光圈和快门；这些设置会改变亮度。
若之前改过相机，可尝试 ISO 100、f/5.6、1/125 s，再比较灯光。

### 相册不见了

请检查是否换了浏览器或本地端口。相册是浏览器本地数据，软件并不把它写进安装文件夹；清理浏览器存储也会清空相册。

### 能不能上传自己的照片、换成人物本人或导入其他模型

当前版本提供内置男女头颈肩人像，不提供照片上传、换脸或自定义模型导入。男女均保留原有眼睛，只显示头、颈和肩部。当前人物是带贴图的制作模型，并非真人扫描。模拟拍摄是保存三维预览，不会调用摄像头。

### 软件会不会上传我的照片

不会。此版本没有照片上传接口、账户系统或统计分析服务。照片和布光方案保存在当前浏览器，需长期保留时请主动下载。

## 十一、macOS / Linux 与源码运行

源码方式需要先具备 Node.js 20 或更新版本。进入解压目录，运行：

```sh
node launch.mjs
```

不需要运行 `npm install`。使用期间保留终端，按 Ctrl+C 停止服务。Windows 源码用户也可用这个方法，或自行编译 `windows/LightfieldLauncher.cs`；编译方式见仓库首页。

## 十二、图片保存与许可文件

JPG 画面不叠加素材来源文字。需要保留的图片许可说明写入下载 JPG 的元数据；完整许可独立保存在包内的 `THIRD-PARTY.md`。本地试配的发型尚未确认全部公开分发条件，请勿把试配素材包直接作为正式发行版上传。

本工具适合练习与拍摄前规划；真实摄影中仍需根据实际脸型、灯具和现场反射微调。

## 十三、用完整布光指南学习

点击顶部「布光指南」。在「11 种布光方法」里选方法，依次阅读“起点怎么放”“按顺序观察”“常见问题怎么改”，再点击底部载入按钮。指南中的三维缩略图由软件本地生成。

切到「6 堂观察练习」，阅读方向、反差、软硬、转头与宽窄光、明暗氛围、焦距与现场拍摄。点击“载入这堂练习”，会关闭指南并载入起点。页面下方显示当前课程的三项观察自查；完成后自行勾选，进度保存在浏览器。它不是自动评分。

完整正文另附在 [人像布光手册](LIGHTING_HANDBOOK.zh-CN.md)，下载后可离线查阅。

## 十四、怎样控制明暗与光比

1. 先载入一种方法，关闭其他灯，只观察主光。左侧“单灯观察”只显示被选灯的照明，环境光暂时归零；“全部”恢复所有已开启灯具。选中一盏未开的灯会看到黑暗或背景，需要在灯具开关中开启它。
2. 在“光影控制”选主/补 1:1、2:1、4:1、8:1。按钮按当前距离计算相对强度，必要时同时降低主光以避免补光超出 100%。这个读数不包含人脸角度、环境光与轮廓光，不是人脸亮暗侧测光。
3. “环境光”整体托起暗部；“背景亮度”只改变布景；“人像曝光补偿”改变人像渲染曝光。一次只动一个滑块。
4. 直方图统计整幅预览，也包括背景。亮度检查用蓝色标记 ≤8/255，红色标记 ≥250/255；这不是 RAW 溢出检测或人脸自动测光。它只在相机视角显示，不会被拍进照片。

## 十五、用 A/B 对照理解变化

1. 调好起点后点击“保存为 A”。
2. 改变灯位、补光、光源大小或曝光中的一个因素。
3. 点击“A/B 对照”，并排查看保存的 A 与当前 B。两图显示各自的方法、焦距、画幅和单灯状态。
4. 可以下载 1440 × 1080 对照 JPG，也可以恢复 A 的全部设置。

A 只保留在当前页面会话，刷新会清空；重要结果请下载或分别拍照保存。相册、自动保存与导出 JSON 是独立功能。辅助线、三角提示与亮度标色不出现在 JPG 中。

## 十六、画幅、姿态和旧版兼容

画幅可选竖幅、方幅、横幅；相机预览框与输出画幅一致。用水平/垂直构图偏移改变留白。抬低头与侧倾范围为 ±15°，转向为 ±60°。构图面板的“复位”恢复 4:5 与零偏移、零俯仰侧倾，保留左右转头与光线。

v1.0 的 JSON 仍可导入，缺少的新参数会补上默认值。v1.1 导出的方案包含新增参数，旧版程序不会完整还原新功能；建议用新版导入。旧版最近照片也可在新版恢复，前提是仍在同一浏览器和端口的本地存储中。

## 按拍摄要求获得不同的观察提示

在摄影棚下方的“你想得到怎样的人像？”中，先选“拍摄要求”：跟随当前方法、自然柔和、立体塑形、清爽高调、戏剧低调、轮廓分离或构图与留白。再选“现在遇到的情况”：整体观察、眼窝/鼻下太暗、脸太平、阴影太硬、人物融入背景或担心面部细节。

提示框分别说明“当前依据”和“接下来试试”。改变灯位、光源大小、环境光或补光后，建议会跟着变化；遇到单灯未开启、无有效灯光或均匀照明对比时，优先说明当前观察模式，避免误判。你明确选择的问题会优先于一般风格建议。

例如：选择“戏剧低调”且环境光较强时，先建议收住环境光；环境光降下来后，提示会转向补光和亮面选择。选择“阴影太硬”时，会结合主光直径与距离给出建议。提示只依据设置，不会自动识别鼻影、眼睛或测得脸部明暗比。点击提示下方的课程链接，可打开对应原理讲解。

画面左侧的信息按钮也会显示当前观察建议。三角参考仅在伦勃朗相关情境中显示，其他方法不会继续套用同一个三角提示。

## 发型和发色怎样参与光影

在右侧「人物与相机」选择「人物」页，先选「男性」或「女性」，再点击发型缩略图。标题、名称和四张效果图会一起随性别更换：

| 人像 | 四种对照 |
| --- | --- |
| 男性 | 原始短茬、立体短发、自然中发、蓬松短卷 |
| 女性 | 无发对照、柔顺短发、中长直发、自然卷发 |

再选择深发色或浅发色。发丝以三维几何参与照明、受影和投影。头部转向时，发根跟随头部，发梢产生受限惯性；打开「发丝摆动」后可点击「轻摆预览」检查动态。关闭摆动后仍保留头、耳廓、颈肩碰撞避让。

光源直径越大、投影离遮挡物越远，阴影过渡通常越柔和。贴近头皮的发丝投影应更紧，远离肩部的发梢投影应更软。这里使用实时近似，极端姿态仍建议结合正面和侧面观察。

建议按以下顺序比较：

1. 固定灯位和曝光，用第一张发型卡片保存 A（男性原始短茬，女性无发对照）。
2. 只切换发型，打开 A/B 对照，观察额头、太阳穴、侧脸和边缘的变化。
3. 使用较弱主光、较强后侧轮廓光，比较深发色和浅发色的亮部与暗部。
4. 减小主光直径，观察发束形成的投影；增大直径后再比较边缘过渡。

改变人像转向、抬低头和侧倾时，发型会跟随头部。切换布光方法会保留发型与发色；相册恢复和 JSON 导入也会恢复发型。v1.0 的旧方案未包含发型时，会以无发模型载入。

### 男性胡须与发型观察

男性第一张卡片保留原贴图中的短茬，其余三张添加对应发型。深浅发色用于添加的发丝，原始短茬和胡须保留自身颜色。胡须已由宽贴片改为细发丝，唇上、脸颊和下巴的长度、方向与密度有所区别。固定曝光，先改变光源方向，再改变光源大小，比较毛发光泽、边缘与下巴暗部。转头、抬低头或侧倾时，胡须按发根所在面部区域跟随；它不提供胡须长度编辑或独立风力模拟。
