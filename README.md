## 下载与启动

### Windows 10 / 11，64 位：推荐便携版

1. 打开本仓库右侧 **Releases**，下载当前发行版附件中名称含 `windows-x64` 的 ZIP。
2. 将压缩包**完整解压**到任意普通文件夹。
3. 双击 `Lightfield.exe`，也可使用 `启动光场.cmd`。
4. 默认浏览器会打开本地摄影棚。使用期间保留「光场」启动器窗口；关闭窗口即可停止服务。

Windows 便携版使用 Windows 自带的 .NET Framework 4.x 启动本地服务，无需安装 Node.js、运行 npm install。
**下载完成后，首次启动也可以断网使用。** 运行环境为 Windows 10 / 11（需 .NET Framework 4.x，通常系统已自带）、支持 WebGL 2 的现代浏览器和显卡。

### macOS / Linux / Windows：源码版

安装 Node.js 20 或更新版本，下载源码并解压，在目录中运行：

```sh
node launch.mjs
```

没有需要安装的 npm 依赖。源码 ZIP 不附带运行环境；Windows 用户若希望免安装，请下载 Releases 的便携版。

默认地址是 `http://127.0.0.1:4173/`。端口占用时会尝试后续九个端口，以启动器显示的地址为准。
请通过本地 HTTP 地址打开，直接双击 `dist/index.html` 会受到浏览器文件加载限制。

## 可以练习什么

- **十一种布光**：伦勃朗光、环状光、分割光、蝴蝶光、上下夹光、宽光、窄光、窗边柔光、高调、低调、逆光与轮廓。
- **完整布光指南**：每种方法的灯位、阴影观察、常见问题与一键练习；六堂原理课程可离线阅读，附三项观察自查。
- **光影控制**：主/补入射估算与 1:1–8:1 快捷设置、单灯观察、环境光、背景亮度、曝光补偿。
- **观察工具**：全画面亮度直方图、亮暗标色、A/B 对照与对照 JPG 下载。
- **三盏独立灯具**：主光、补光、轮廓光；角度、俯照、距离、强度、光源大小和色温调节。
- **两种视角**：相机实时预览与可环绕观察的三维摄影棚。
- **灯位图**：拖动灯具，或聚焦灯具后使用方向键调整。
- **人像与相机**：头部转向、俯仰、侧倾、构图偏移、肤色或石膏材质、六种背景、12–300 mm 焦距、传感器、光圈、ISO 和 30 s–1/8000 s 快门。
- **男女与发型**：右侧「人物」切换男性或女性；四张发型卡片随性别同步更换，女性四张效果照片在本机生成并缓存。女性模型保留睁眼、睫毛和头颈肩；男性也保留原有睁眼，胡须采用细发丝。
- **发丝与阴影**：深浅发色、固定发根与发梢惯性摆动，按头部表面、耳廓、颈部与肩部避让；光源越大，离遮挡物较远的阴影边缘越柔和。
- **模拟拍摄**：空格键或快门按钮按 12 种画幅或自定义比例拍摄 JPG，保留最近八张照片，支持下载与恢复布光。
- **方案管理**：JSON 导入、导出以及浏览器自动保存。

## 相机与构图

右侧打开 **「相机」**，四个折叠模块分别管理画幅、快门、镜头和距离。

- **画幅**：12 种摄影与电影比例、自定义宽高及横竖互换；三分法交点、中心十字与九宫格仅用于预览，不会印入照片。
- **镜头**：12–300 mm 连续焦距与 23 个预设；全画幅、两种 APS-C、M4/3 或自定义传感器，显示裁切后的水平及垂直视角。
- **距离**：0.2–50 m，步长 0.05 m；可选双眼、面部、头部或胸像中心，以三维直线距离读数。人物尺寸保持不变。
- **工作模式**：默认固定相机位置；「保持主体构图大小」通过自动移机补偿焦距、画幅或传感器变化，仍保留真实透视差别。
- **快门**：长曝光到高速快门、挡位滑块与手动秒数或分数输入；当前没有真实运动模糊，开关明确显示不可用。

[相机完整使用说明、拍摄示例及模拟限制](docs/CAMERA_GUIDE.zh-CN.md) · [相机测试覆盖](docs/CAMERA_TEST_REPORT.zh-CN.md)

## 从指南开始练习

顶部「布光指南」可切换十一种方法和六堂课程。底部载入后回到摄影棚操作，页面下方保留三项观察自查。完整讲解见 [离线人像布光手册](docs/LIGHTING_HANDBOOK.zh-CN.md)。

## 快速练习伦勃朗光

选择「伦勃朗光」，微调主光，使鼻影与脸颊阴影连接，在暗侧眼睛下方留下一小块三角亮区。
预设角度只是起点，亮区会随着脸型与转头方向改变。可按住对比按钮观察均匀照明。

## 离线与数据

模型、纹理、图标、Three.js 和加载器全部随软件提供。程序运行时不会从 CDN 下载文件，也没有统计分析或上传接口。
照片与方案只保存在当前浏览器的本地存储中，清理浏览器数据会清除它们；重要照片和方案请主动导出。
切换浏览器或端口也会切换本地存储空间。全部布光与指南内容可离线使用。

## 模拟范围

软阴影贴图近似柔光与接触阴影。光圈、ISO 与曝光补偿参与亮度近似；快门单独记录，不直接改变亮度。当前不支持真实运动模糊、闪光同步、景深、镜头像差或完整现场反射。
灯光强度为相对单位，无法换算成灯具瓦秒或测光表读数。不做自动三角光识别；实拍仍需按现场人脸与灯具微调。

## 升级与已知限制

旧 JSON 会迁移到新的相机结构；旧快门倒数会转换为秒数。建议先导出重要方案和照片。旧版、新本地预览使用过不同的本地存储名称；迁移时请导入导出的 JSON，不保证自动找回其他浏览器或端口的数据。

人物只保留头、颈和肩膀。选择远距离预设仍可练习视角和主体大小，但不会自动生成半身或全身。相机靠近时只提示可能裁切，不会改写你的参数。头部尺寸用于场景比例校准，不能作为医学或实景测量。

密集卷发仍较耗性能；可切换较短发型或降低浏览器缩放和窗口尺寸。网页的约束式发梢摆动与 Blender 原生 Hair Dynamics 是两个系统，网页包不包含实验中的 Blender 工程或物理缓存。

完整版本变更见 [CHANGELOG.md](CHANGELOG.md)。

## 开发与验证

```sh
node --test
node --check dist/app.js
node launch.mjs --no-browser --port 4200
```

源文件在 `dist/`，无需构建。服务仅监听 `127.0.0.1`。

Windows 启动器源码为 `windows/LightfieldLauncher.cs`，仅依赖 .NET Framework 内置库，无 NuGet 依赖。
可用系统 C# 编译器构建：

```powershell
& "$env:WINDIR\Microsoft.NET\Framework64\v4.0.30319\csc.exe" /nologo /target:winexe /platform:x64 /langversion:5 /optimize+ /out:Lightfield.exe /reference:System.Windows.Forms.dll /reference:System.Drawing.dll windows/LightfieldLauncher.cs
```

`scripts/build-windows.ps1` 也提供同样的构建过程；无需更改 PowerShell 执行策略。

## 本版新增的观察提示与发型对照

- 观察建议根据拍摄要求、遇到的问题、当前灯位、环境光、光比和单灯状态分别回应，并链接对应课程。它按参数给出观察方向，不自动识别人脸或评价作品。
- 男性保留原始贴图中的短茬，并提供立体短发、自然中发、蓬松短卷；女性保留无发对照，并提供柔顺短发、中长直发、自然卷发。深浅发色参与实时照明与投影，发丝摆动采用受限弹簧与碰撞避让近似。
- 发型与发色随照片、自动保存和 JSON 方案保留；切换布光方法保留当前发型，便于固定人物比较光线。
